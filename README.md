# CampusConnect — Interactive Campus Navigation & Spatial Resource Module

A full-stack module that renders campus locations (academic blocks, offices,
libraries, canteens, hostels, emergency points, parking) on an interactive
Leaflet.js map, with category filtering, an events layer, and a role-based
admin dashboard for managing everything.

```
campusconnect/
├── backend/     Express REST API (JWT auth, JSON file storage)
└── frontend/    React + Vite app (Leaflet map, Tailwind CSS)
```

## Quick start

### 1. Backend

```bash
cd backend
npm install
npm run seed      # creates data/db.json with sample data + default admin
npm run dev        # http://localhost:5000
```

Default admin login: **admin / admin123** — change this before deploying
anywhere public (edit `utils/seed.js` or add a "change password" endpoint).

### 2. Frontend

```bash
cd frontend
npm install
cp .env.example .env   # points the app at http://localhost:5000/api
npm run dev             # http://localhost:5173
```

Open `http://localhost:5173`. The map view works immediately with the seeded
sample data; sign in at `/admin/login` to add, edit, or delete locations,
categories, and events.

## Before you use this for real

The seeded coordinates in `backend/utils/seed.js` are placeholders scattered
around a single point (`CAMPUS_CENTER`) — **not your actual campus**. Two ways
to fix that:

1. Fastest: log into the admin dashboard and edit each location's latitude/
   longitude to the real coordinates (right-click a spot on Google Maps to
   copy its coordinates).
2. Or: edit `CAMPUS_CENTER` and the `locations` array in `seed.js` directly,
   then re-run `npm run seed` (this resets all data).

Also update `CAMPUS_CENTER` in `frontend/src/pages/MapPage.jsx` so the map
opens centered on your campus instead of the placeholder point.

## How it's built

**Backend** (`backend/`)
- `server.js` — Express app, mounts all routes
- `routes/` — `auth`, `categories`, `locations`, `events` (REST, JSON)
- `middleware/auth.js` — JWT verification + `requireAdmin` gate
- `utils/db.js` — tiny file-backed JSON "database" (swap for Postgres/Mongo
  later without touching route logic)
- `utils/seed.js` — one-time seed script for sample data + admin user
- `data/db.json` — generated by the seed script (git-ignored)

Auth: `POST /api/auth/login` returns a JWT; protected routes require
`Authorization: Bearer <token>` and `role: admin` for writes. Public `GET`
routes need no auth, matching the brief's "public map, admin-managed data"
split.

**Frontend** (`frontend/`)
- `pages/Home.jsx` — marketing/landing page
- `pages/MapPage.jsx` — the interactive map: search, category filters,
  upcoming events list, click-to-fly-to-venue
- `pages/AdminLogin.jsx`, `pages/AdminDashboard.jsx` — auth + CRUD tabs for
  locations, categories, and events
- `context/AuthContext.jsx` — holds the JWT + current user, exposes
  `login`/`logout`/`isAdmin`
- `services/api.js` — one Axios client, auto-attaches the stored token
- `components/` — Navbar, Footer, CategoryFilter, Modal, FlyTo (Leaflet
  camera control), ProtectedRoute

Design tokens (see `tailwind.config.js`): deep indigo (`#16233F`) + amber
accent (`#E8A33D`) on a warm off-white background, Space Grotesk for
headings and Inter for body text — chosen to read as a wayfinding/utility
tool rather than a generic SaaS template.

## Extending it

- **Real database**: replace the functions in `backend/utils/db.js` with
  Postgres/Mongo queries; no route file needs to change its logic, only its
  data calls.
- **Image uploads**: each location already has an `image` field (currently
  unused) — wire up a file upload endpoint and render it in the map popup
  and admin form.
- **Route directions**: Leaflet Routing Machine (`leaflet-routing-machine`)
  can be dropped into `MapPage.jsx` to draw a walking path from the user's
  location to a selected pin.
- **Event registration**: the abstract mentions an existing event
  registration system on the main CampusConnect platform — `events.location`
  is already returned by the API so that platform's registration page can
  deep-link into this map.
